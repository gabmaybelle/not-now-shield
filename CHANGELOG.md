# Changelog

## 1.2.0 for Minecraft 1.20.1

Not Now, Shield for Minecraft 1.20.1, on Fabric and on Forge. Your shield is drawn lower in first person, resting or raised, so it covers less of your view. It still blocks exactly as before; only the picture moves, and only on your own screen. Modded shields are lowered too.

The 26.2 and 26.3 version also lets tools work with a shield in your off-hand. Minecraft 1.20.1 doesn't have that problem, so this version leaves tools alone.

**Which file:** `not-now-shield-fabric` for Fabric (needs Fabric Loader 0.15 or newer; Fabric API isn't needed), `not-now-shield-forge` for Forge 47 or newer. Both need Java 17. Client-side only.
